# tools

The Windows app looks for these executables in this folder (they are not tracked in git because of their size):

- `yt-dlp.exe` - https://github.com/yt-dlp/yt-dlp/releases/latest
- `ffmpeg.exe` and `ffprobe.exe` - https://www.gyan.dev/ffmpeg/builds/ ("full" build)

They are copied next to `DVVdownloader.exe` on build/publish.
